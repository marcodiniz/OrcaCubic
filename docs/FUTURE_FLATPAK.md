# Future feature: Flatpak package

## Status

**Planned — not currently released or supported.**

A Flatpak package is being considered as a future Linux installation option for OrcaCubic. The first Linux package will use AppImage while the Flatpak-specific behavior is validated.

Before Flatpak is offered as a download, it needs:

- OrcaCubic-specific application identity, icon, description, and update metadata;
- permission to connect to printers on the local network;
- permission to run OrcaCubic's bundled printer helper;
- working Device dashboard and camera behavior inside the sandbox;
- verified access to user-selected model and print files;
- installation, launch, update, and removal testing on a Linux desktop;
- a safe Kobra X connection and upload test;
- a supervised print test before printer integration is advertised as supported.

Flatpak will remain separate from the AppImage release until those checks pass.
